About XHTML

XHTML (Extensible HyperText Markup Language) is a stricter version of HTML. It follows XML rules, making web pages more structured and easier to maintain.


XHTML Rules Used

  • All tags are written in lowercase.
  • Every opening tag has a closing tag.
  • All attribute values are enclosed in double quotes.
  • Elements are properly nested.
  • Empty elements are self-closing (<br />, <hr />, <meta />).
