Internet Protocols Using Browser Developer Tools

HTML Practical Demonstration

Objective

To observe the communication between a web browser and a web server using the Network tab in Browser Developer Tools.

Steps to Observe Network Activity

  1. Open Google Chrome or Microsoft Edge.
  2. Open any website.
  3. Press F12 or Right Click → Inspect.
  4. Select the Network tab.
  5. Refresh the webpage.
  6. Observe the network requests.
  7. Click any request to view its details.

Observed Parameters

Parameter Description
URL Address of the requested resource.
Protocol HTTP/HTTPS communication protocol.
Request Method GET or POST request.
Status Code 200 OK, 404 Not Found, 500 Server Error etc.
File Type HTML, CSS, JavaScript, Image, JSON etc.
Size Downloaded file size.
Loading Time Time required to load the resource.

Sample Observation

URL Protocol Method Status Type Size Time
index.html HTTPS GET 200 OK Document 18 KB 24 ms
style.css HTTPS GET 200 OK CSS 6 KB 12 ms
logo.png HTTPS GET 200 OK Image 95 KB 36 ms

Conclusion

The Browser Developer Tools Network tab helps analyze webpage requests, monitor loading performance, inspect HTTP/HTTPS protocols, and troubleshoot network-related issues efficiently.
