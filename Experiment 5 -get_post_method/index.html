HTML Form - GET and POST Method Demo

Note: HTML forms support only GET and POST methods.

GET Method

The GET method sends data through the URL. It is commonly used for searching and retrieving information.

Observation: After clicking the button, check the browser URL.

Example:

index.html?student_name=Rahul&department=IT

POST Method

The POST method sends data inside the request body. The submitted data is not visible in the URL.

Observation: The entered information is not displayed in the browser address bar.

Difference Between GET and POST

Feature GET POST
Purpose Retrieve Data Submit Data
Data Visibility Visible in URL Hidden from URL
Security Less Secure More Secure
Data Length Limited No Practical Limit
Example Search Form Login Form
